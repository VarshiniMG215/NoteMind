A process is a program in execution. A thread is a lightweight unit of execution inside a process; threads of the same process share memory and open files. Deadlock occurs when processes wait for each other forever. The four necessary conditions are mutual exclusion, hold and wait, no preemption, and circular wait. Breaking any one condition prevents deadlock. Round robin scheduling gives each process a fixed time quantum, which improves response time but adds context switching overhead. Paging divides memory into fixed-size frames and pages to avoid external fragmentation. A page fault happens when a required page is not in main memory and must be loaded from disk.
